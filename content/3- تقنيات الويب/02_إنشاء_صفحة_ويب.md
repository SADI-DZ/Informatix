# 💻 إنشاء صفحة ويب بلغة HTML
**المادة:** تقنيات الويب | **المستوى:** السنة الأولى ثانوي (أدبي + علمي)

---

## 📌 مقدمة سريعة

هل تساءلت يومًا كيف تُبنى المواقع الإلكترونية؟
الجواب يبدأ بـ **HTML** — اللغة الأساسية لبناء كل صفحة ويب تراها على الإنترنت.
في هذا الدرس ستكتب أول صفحتك بنفسك!

---

## ⚡ ملخص سريع

| المفهوم | التعريف المختصر |
|---------|----------------|
| **HTML** | لغة ترميز لبناء صفحات الويب |
| **الوسم (Tag)** | علامة بين `< >` تحدد نوع المحتوى |
| **الوسم المزدوج** | له فتح `<وسم>` وإغلاق `</وسم>` |
| **الوسم المنفرد** | لا يحتاج إغلاق مثل `<br>` و`<hr>` |
| **الخاصية (Attribute)** | معلومة إضافية داخل الوسم مثل `style` و`src` |

---

## 🗺️ مخطط: هيكل صفحة HTML

```
📄 ملف HTML
│
├── <!DOCTYPE html>        ← إخبار المتصفح بنوع الملف
│
└── <html>                 ← جذر الصفحة
    │
    ├── <head>             ← معلومات عامة (لا تظهر في الصفحة)
    │   └── <title>        ← عنوان يظهر في شريط المتصفح
    │
    └── <body>             ← المحتوى المرئي للصفحة
        ├── عناوين (h1...h6)
        ├── فقرات (p)
        ├── صور (img)
        ├── قوائم (ol / ul)
        ├── جداول (table)
        └── روابط (a)
```

> 💡 **اقتراح:** أضف هنا رسمًا توضيحيًا (Infographic) يشرح هيكل HTML بالألوان.

## 📖 الشرح المبسط

### 🔹 1. أساسيات الوسوم

كل وسم له **فتح** و**إغلاق**:
```html
<p>هذا نص في فقرة</p>
```
الوسوم الداخلية **تُغلق أولًا** قبل الخارجية — مثل الصناديق المتداخلة.

---

### 🔹 2. العناوين — من الأكبر للأصغر

| الوسم | الحجم | الاستخدام |
|-------|-------|-----------|
| `<h1>` | ضخم جدًا | العنوان الرئيسي للصفحة |
| `<h2>` | كبير | عنوان قسم |
| `<h3>` | متوسط | عنوان فرعي |
| `<h4>` إلى `<h6>` | صغير | عناوين أقل أهمية |

---

### 🔹 3. تنسيق النصوص

| الوسم | التأثير | مثال |
|-------|---------|-------|
| `<b>` | **خط عريض** | `<b>مهم</b>` |
| `<i>` | *خط مائل* | `<i>ملاحظة</i>` |
| `<u>` | خط تحتي | `<u>تسطير</u>` |
| `<br>` | سطر جديد | — |
| `<hr>` | خط أفقي فاصل | — |

---

### 🔹 4. خصائص التنسيق (style)

```html
<p style="color:red">نص أحمر</p>
<p style="font-size:20px">نص كبير</p>
<p style="text-align:center">نص في المنتصف</p>
<p dir="rtl">نص من اليمين لليسار</p>
```

---

### 🔹 5. القوائم

**قائمة مرتبة (بأرقام):**
```html
<ol>
  <li>رياضيات</li>
  <li>فيزياء</li>
  <li>لغة عربية</li>
</ol>
```
**النتيجة:** 1. رياضيات  2. فيزياء  3. لغة عربية

**قائمة غير مرتبة (بنقاط):**
```html
<ul>
  <li>آداب وفلسفة</li>
  <li>لغات أجنبية</li>
</ul>
```

---

### 🔹 6. الجداول

```html
<table border="1">
  <tr>
    <th>الاسم</th>
    <th>المعدل</th>
  </tr>
  <tr>
    <td>محمد</td>
    <td>15</td>
  </tr>
</table>
```

| الوسم | الدور |
|-------|-------|
| `<table>` | إنشاء الجدول |
| `<tr>` | صف جديد |
| `<th>` | خلية عنوان (عريض + مركز) |
| `<td>` | خلية بيانات عادية |

---

### 🔹 7. الصور والروابط

**إضافة صورة:**
```html
<img src="photo.jpg" width="200" height="150" alt="وصف الصورة">
```

**إضافة رابط:**
```html
<a href="https://google.com">اضغط هنا</a>
```

## 🧪 مثال محلول كامل

**المطلوب:** صفحة شخصية بسيطة

```html
<!DOCTYPE html>
<html>
  <head>
    <title>صفحتي الشخصية</title>
  </head>
  <body>

    <!-- العنوان الرئيسي -->
    <h1 style="color:green; text-align:center">أحمد بن علي</h1>
    <hr>

    <!-- التعريف بالنفس -->
    <p dir="rtl">
      أنا التلميذ <b>أحمد بن علي</b>،
      عمري <u>16</u> سنة،
      أدرس في شعبة <i>سنة أولى علمي</i>.
    </p>
    <hr>

    <!-- قائمة المواد -->
    <ol dir="rtl">
      <li>رياضيات</li>
      <li>لغة عربية</li>
      <li>فيزياء</li>
    </ol>
    <hr>

    <!-- جدول النتائج -->
    <table border="1">
      <tr>
        <th>المادة</th>
        <th>الأستاذ</th>
        <th>المعدل</th>
      </tr>
      <tr>
        <td>رياضيات</td>
        <td>الأستاذ مراد</td>
        <td>15.50</td>
      </tr>
    </table>
    <hr>

    <!-- رابط مفضل -->
    <a href="https://google.com">موقعي المفضل</a>

  </body>
</html>
```

**نتيجة الكود:**
- ✅ عنوان أخضر في المنتصف
- ✅ فقرة تعريفية بتنسيق
- ✅ قائمة مرتبة
- ✅ جدول بحدود
- ✅ رابط قابل للضغط

---

## ⚠️ الأخطاء الشائعة

| ❌ الخطأ | ✅ الصحيح |
|---------|----------|
| نسيان إغلاق الوسم `<p>` | `<p>النص</p>` ← لا بد من الإغلاق |
| كتابة `href=photo.jpg` بدون تنصيص | `src="photo.jpg"` ← التنصيص إلزامي |
| إغلاق وسم خارجي قبل الداخلي | `<b><i>نص</i></b>` ← الداخلي يُغلق أولًا |
| نسيان `<!DOCTYPE html>` | يجب أن يكون السطر الأول دائمًا |
| حفظ الملف بامتداد `.txt` | احفظ دائمًا بامتداد `.html` |

## ✏️ تمارين للتطبيق

**🟢 سهل:**
1. اكتب كودًا يعرض عنوانًا كبيرًا أحمر اللون يقول "مرحبًا بالعالم".
2. أنشئ قائمة غير مرتبة بثلاثة ألوان.

**🟡 متوسط:**

3. صحح الكود التالي:
```html
<html>
  <body>
    <h1>صفحتي
    <p>مرحباً<p>
    <img href=photo.jpg>
  </body>
</html>
```

4. أنشئ جدولًا بثلاثة أعمدة: **الاسم – المادة – العلامة** مع صفين من البيانات.

**🔴 تحدي:**

5. أنشئ صفحة ويب كاملة تحتوي على: عنوان رئيسي، فقرة تعريفية، قائمة مرتبة، جدول، صورة، ورابط — مع تنسيق مناسب.
