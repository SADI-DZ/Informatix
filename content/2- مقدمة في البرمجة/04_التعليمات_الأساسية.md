# ⚙️ التعليمات الأساسية

> **المادة:** مقدمة في البرمجة | **المستوى:** السنة أولى علمي

---

## 🎯 ماذا ستتعلم؟

في هذا الدرس ستتعلم **5 تعليمات أساسية** تشكّل عمود فقرات أي خوارزمية:
الإسناد، القراءة، الكتابة، الشرط، والتكرار.

---

## 📌 ملخص سريع

| التعليمة | الوظيفة | المثال |
|---------|---------|--------|
| `←` الإسناد | إعطاء قيمة لمتغير | `A ← 20` |
| `Read` | قراءة مدخل من لوحة المفاتيح | `Read(x)` |
| `Write` | طباعة نتيجة على الشاشة | `Write(x)` |
| `If...EndIf` | تنفيذ تعليمة بشرط | `If x > 0 then...` |
| `While...EndWhile` | تكرار طالما الشرط محقق | `While i <= 10 do...` |
| `For...EndFor` | تكرار عدد معروف من المرات | `For i ← 1 To 10 do...` |

---

## 1️⃣ تعليمة الإسناد

> إعطاء قيمة لمتغير — نستخدم السهم `←`

```
A ← 20         ← A تساوي 20
B ← A + 5      ← B تساوي قيمة A زائد 5
i ← i + 1      ← نزيد قيمة i بـ 1
```

**قاعدة:** الطرف الأيمن يُحسب أولًا، ثم يُخزّن في الطرف الأيسر.

---

## 2️⃣ تعليمتا القراءة والكتابة

```
Read(a)         ← المستخدم يُدخل قيمة تُحفظ في a
Write(a)        ← تُطبع قيمة a على الشاشة
Write("Hello")  ← تُطبع النص "Hello" مباشرة
```

---

## 3️⃣ التعليمة الشرطية — 3 أشكال

### الشكل البسيط — قرار واحد فقط

```
If <الشرط> then
    تعليمات
EndIf
```

**مثال:**
```
If x < 10 then
    Write("Correct");
EndIf
```

---

### الشكل الاختياري — قراران (نعم أو لا)

```
If <الشرط> then
    تعليمة 1        ← عند تحقق الشرط
Else
    تعليمة 2        ← عند عدم تحققه
EndIf
```

**مثال:**
```
If x > 0 then
    Write("Positive");
Else
    Write("Negative");
EndIf
```

---

### الشكل المتعدد — أكثر من قرارين

```
If <شرط 1> then
    تعليمة 1
ElseIf <شرط 2> then
    تعليمة 2
Else
    تعليمة 3
EndIf
```

**مثال — تقييم الدرجات:**
```
If note >= 15 then
    Write("Excellent");
ElseIf note >= 10 then
    Write("Average");
Else
    Write("Bad");
EndIf
```

> 💡 **اقتراح:** أضف رسمًا توضيحيًا يقارن بين الأشكال الثلاثة

---

## 4️⃣ التعليمة التكرارية — شكلان

### الشكل While — عدد مرات غير معروف

```
While <الشرط> do
    تعليمات
EndWhile
```

**متى تستخدمه؟** عندما لا تعرف كم مرة ستتكرر الحلقة مسبقًا.

```
Algorithm Count_To_Ten
Var
    i: Integer;
Begin
    i ← 0;
    While i <= 10 do
        Write(i);
        i ← i + 1;
    EndWhile
End
```

---

### الشكل For — عدد مرات معروف

```
For متغير ← قيمة ابتدائية To قيمة نهائية do
    تعليمات
EndFor
```

**متى تستخدمه؟** عندما تعرف بالضبط كم مرة ستتكرر الحلقة.

```
Algorithm Multi_Three
Var
    i: Integer;
Begin
    For i ← 1 To 10 do
        Write(i * 3);
    EndFor
End
```

**النتيجة:** `3  6  9  12  15  18  21  24  27  30`

---

## 📊 مقارنة While و For

| | `While` | `For` |
|--|---------|-------|
| **متى؟** | عدد مرات غير معروف | عدد مرات معروف |
| **تهيئة العداد** | يدويًا قبل الحلقة | تلقائي في السطر الأول |
| **تحديث العداد** | يدويًا داخل الحلقة | تلقائي |
| **مثال** | قراءة حتى إدخال 0 | طباعة أعداد من 1 إلى N |

---

## ✅ أمثلة محلولة كاملة

### مثال 1 — محيط ومساحة الدائرة

```
Algorithm Circle
Var
    r, A, P: Real;
Const
    Pi ← 3.14;
Begin
    Read(r);
    A ← Pi * r * r;
    P ← 2 * Pi * r;
    Write(A);
    Write(P);
End
```

---

### مثال 2 — الفئة الرياضية حسب العمر

```
Algorithm Sport_Category
Var
    age: Integer;
Begin
    Read(age);
    If (age < 6) then
        Write("Out of category");
    ElseIf (age <= 7) then
        Write("Chick");
    ElseIf (age <= 9) then
        Write("Pupil");
    ElseIf (age <= 11) then
        Write("Minime");
    ElseIf (age <= 15) then
        Write("Cadet");
    Else
        Write("Out of category");
    EndIf
End
```

> 💡 **اقتراح:** أضف هنا تمرينًا تفاعليًا يطلب من التلميذ إدخال عمر ويُظهر الفئة

---

### مثال 3 — مجموع الأعداد الفردية من 1 إلى N

```
Algorithm Sum_Odd
Var
    n, sum, i: Integer;
Begin
    Read(n);
    sum ← 0;
    i ← 1;
    While (i <= n) do
        sum ← sum + i;
        i ← i + 2;
    EndWhile
    Write(sum);
End
```

## 🧩 تمارين تدريجية

### 🟢 سهل

1. اكتب خوارزمية تقرأ عددي `A` و`B` وتطبع الأكبر بينهما.
2. اكتب خوارزمية تحسب عدد الساعات بالدقائق وبالثواني.

### 🟡 متوسط

3. اكتب خوارزمية تقرأ كلمة وتطبعها `n` مرة.
4. اكتب خوارزمية تقرأ معاملات معادلة `Ax + B = 0` وتطبع الحل.

### 🔴 تحدي

5. اكتب خوارزمية تطلب من المستخدم إدخال أعداد متتالية، وتحسب مجموعها وتتوقف عند إدخال الرقم `0`.

---

## ⚠️ الأخطاء الشائعة

- ❌ **نسيان `i ← i + 1` داخل While** — يؤدي إلى حلقة لا نهائية تجمّد البرنامج
- ❌ **استخدام `For` عندما عدد المرات غير معروف** — استخدم `While` بدلًا
- ❌ **نسيان `Else`** — إذا لم يتحقق أي شرط، البرنامج لن يطبع شيئًا
- ❌ **ترتيب شروط `ElseIf` الخاطئ** — ابدأ دائمًا بالشرط الأكبر أو الأدق
- ❌ **مقارنة نص بعدد** — لا تكتب `If name > 5` لأن `name` من نوع `String`

---

## ⚡ مراجعة سريعة قبل الفرض

```
✔ الإسناد: A ← القيمة
✔ Read = مدخل من المستخدم
✔ Write = مخرج على الشاشة
✔ If / ElseIf / Else / EndIf = التعليمة الشرطية
✔ While = تكرار (عدد مرات غير معروف) — يحتاج تحديث يدوي للعداد
✔ For = تكرار (عدد مرات معروف) — العداد تلقائي
✔ كل حلقة While تحتاج: تهيئة + شرط + تحديث
✔ كل خوارزمية: Var + Begin...End
```
