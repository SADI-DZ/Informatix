# 📊 المخططات الانسيابية (الشامل)

> **المادة:** مقدمة في البرمجة | **المستوى:** السنة أولى علمي

---

## 🎯 ماذا ستتعلم في هذا الدرس؟

في هذا الدرس ستتعلم كيف **ترسم مخططًا انسيابيًا** لحل أي مشكلة برمجية بطريقة منظمة وواضحة. المخطط الانسيابي هو **أساس البرمجة** — قبل أن تكتب أي كود، يجب أن تعرف كيف ترسم الخطوات.

ستكتشف في هذا الدرس الشامل:
1. الرموز الهندسية الأساسية.
2. كيفية تمثيل العمليات الحسابية.
3. كيفية اتخاذ القرارات (**الشرط**).
4. كيفية تكرار المهام (**الحلقة التكرارية**).

---

## 📌 ملخص الرموز الأساسية

| الشكل | الاسم | الوظيفة |
|-------|-------|---------|
| 🔵 بيضاوي | البداية / النهاية | `START` و `END` |
| 📋 متوازي الأضلاع | المدخلات / المخرجات | `READ` قراءة — `WRITE` طباعة |
| ▭ مستطيل | العمليات | الحسابات والتعليمات |
| 🔷 معين | الشرط | قرار `TRUE` أو `FALSE` |
| ⭕ دائرة مع سهم | الحلقة التكرارية | تكرار ما دام الشرط محققًا |
| ➡️ سهم | خط الانسياب | الاتجاه المنطقي |

---

## 🔷 الجزء الأول: البنية التسلسلية (Sequential)

المخطط الانسيابي مثل **خريطة الطريق** — يرشدك من نقطة البداية إلى النتيجة خطوة بخطوة.

كل مشكلة تمر بـ **3 مراحل**:
- **أدخل** ما تحتاجه (المعطيات)
- **افعل** شيئًا بها (العمليات)
- **اخرج** بالنتيجة (المخرجات)

### ✅ مثال محلول — حساب مساحة مربع
**المطلوب:** أنشئ مخططًا انسيابيًا لحساب مساحة مربع طول ضلعه `a`

```
     ┌─────────────┐
     │    START    │
     └──────┬──────┘
            ↓
     ┌─────────────┐
     │   READ (a)  │
     └──────┬──────┘
            ↓
     ┌─────────────┐
     │  S ← a × a  │
     └──────┬──────┘
            ↓
     ┌─────────────┐
     │  WRITE (S)  │
     └──────┬──────┘
            ↓
     ┌─────────────┐
     │     END     │
     └─────────────┘
```

## 🔶 الجزء الثاني: الشرط (Condition)

الشرط هو **اختبار منطقي** ينتج عنه جوابان فقط: نعم أو لا.

### مثال — إشارة العدد
**المطلوب:** اقرأ عددًا صحيحًا وطبع إشارته

```
         ┌─────────────┐
         │   READ (N)  │
         └──────┬──────┘
                ↓
            ◇ N > 0 ◇
           ✅ /     \ ❌
            ↓         ↓
   WRITE("Positive") WRITE("Negative")
            ↓         ↓
            └────┬────┘
                 ↓
         ┌─────────────┐
         │     END     │
         └─────────────┘
```

---

## 🔁 الجزء الثالث: الحلقة التكرارية (Loop)

بنية تسمح بـ **تكرار تعليمات** عدة مرات حسب شرط معين.

### العداد — 3 خصائص أساسية
1. **قيمة ابتدائية:** (مثال: `i = 1`).
2. **شرط التوقف:** (مثال: `i <= 10`).
3. **المحرك (الزيادة):** (مثال: `i = i + 1`).

### مثال — طباعة الأعداد من 1 إلى 10
```
         ┌─────────────┐
         │    i ← 1    │
         └──────┬──────┘
                ↓
          ◇ i <= 10 ◇ ──── ❌ ────→ END
               ✅ ↓
         ┌─────────────┐
         │  WRITE (i)  │
         └──────┬──────┘
                ↓
         ┌─────────────┐
         │  i ← i + 1  │
         └──────┬──────┘
                │
                └────────↑ (رجوع للشرط)
```

---

## 🧩 تمارين تطبيقية

1. **سهل:** أنشئ مخططًا انسيابيًا يقرأ عددًا ويطبع نوعه **(زوجي أو فردي)**.
2. **متوسط:** أنشئ مخططًا انسيابيًا يقرأ **طول وعرض مستطيل** ويحسب **محيطه**.
3. **تحدي:** أنشئ مخططًا انسيابيًا يطبع الأعداد الزوجية من `1` إلى `N`.

---

## ⚡ مراجعة سريعة

```
✔ المخطط الانسيابي = رسم مرتب لخطوات الحل
✔ 3 مراحل: مدخلات → عمليات → مخرجات
✔ البيضاوي = START / END
✔ المستطيل = الحسابات
✔ المعين = القرارات (TRUE/FALSE)
✔ الحلقة تحتاج: بداية + شرط + زيادة
```
