# 🧠 مدخل إلى الخوارزمية

> **المادة:** مقدمة في البرمجة | **المستوى:** السنة أولى علمي

---

## 🎯 ماذا ستتعلم؟

ستتعلم كيف **تكتب خوارزمية** بالشكل الصحيح — من تسمية المتغيرات، إلى كتابة التعليمات، إلى تحديد نوع كل بيانة.

---

## 📌 ملخص سريع

| المفهوم | التعريف |
|--------|---------|
| **الخوارزمية** | مجموعة خطوات مرتبة ومنتهية لحل مشكلة معينة |
| **المتغير** | خانة في الذاكرة تحمل قيمة قابلة للتغيير |
| **الثابت** | قيمة محددة لا تتغير طوال تنفيذ البرنامج |
| **المعرّف** | الاسم الذي نطلقه على المتغير أو الثابت |

---

## 🏗️ هيكل الخوارزمية — 3 أقسام

```
┌──────────────────────────────────────┐
│        Algorithm  اسم_الخوارزمية    │  ← الرأس: اسم فقط
├──────────────────────────────────────┤
│  Var                                 │
│       المتغيرات                      │  ← التصريحات
│  Const                               │
│       الثوابت                        │
├──────────────────────────────────────┤
│  Begin                               │
│       التعليمات                      │  ← التعليمات
│  End                                 │
└──────────────────────────────────────┘
```

---

## 🔢 أنواع البيانات — 5 أنواع أساسية

| النوع | ما يمثله | مثال |
|-------|---------|------|
| `Integer` | أعداد صحيحة | `5`, `-3`, `0` |
| `Real` | أعداد حقيقية (بفاصلة) | `3.14`, `2.5` |
| `Character` | حرف واحد أو رمز | `'A'`, `'z'` |
| `String` | كلمة أو جملة | `"Ahmed"`, `"Bonjour"` |
| `Boolean` | قيمة منطقية | `True` أو `False` |

> 💡 **نصيحة:** اختر النوع المناسب — العمر `Integer`، المعدل `Real`، الاسم `String`

---

## ✍️ كيف تُصرّح بالمتغيرات والثوابت؟

### المتغيرات

```
Var
    اسم_المتغير : النوع;

مثال:
    X, Y : Integer;
    Nom  : String;
    Moy  : Real;
```

### الثوابت

```
Const
    اسم_الثابت ← القيمة;

مثال:
    Pi    ← 3.14;
    Ville ← "Tlemcen";
```

## 📋 قواعد تسمية المعرّفات — 4 قواعد فقط

```
القاعدة 1: يبدأ بحرف لا برقم
القاعدة 2: يحتوي فقط على حروف، أرقام، أو _ (بدون فراغات)
القاعدة 3: لا يستخدم الكلمات المحجوزة مثل: Read, If, True...
القاعدة 4: يجب أن يكون له معنى واضح
```

### جدول التمييز

| ✅ صحيح | ❌ خاطئ | السبب |
|--------|--------|-------|
| `X1` | `1X` | يبدأ برقم |
| `Student_name` | `Student name` | يحتوي على فراغ |
| `Right` | `True` | كلمة محجوزة |
| `Moy_Bac` | `N°phone` | رمز خاص (°) |

## 📖 الشرح المبسط

**الخوارزمية = وصفة طبخ للحاسوب**

تمامًا كما تحتاج وصفة الطبخ إلى قائمة المكونات (التصريحات) وخطوات الطهي (التعليمات)، الخوارزمية أيضًا تحتاج إلى:
- 📝 **قائمة المتغيرات** — ما الذي ستستخدمه
- ⚙️ **التعليمات** — ما الذي ستفعله خطوة بخطوة

---

## ✅ مثال محلول — مساحة المربع

**المطلوب:** اكتب خوارزمية لحساب مساحة مربع طول ضلعه `a`

### التحليل

| | |
|--|--|
| **المدخلات** | الضلع `a` |
| **العمليات** | `S = a × a` |
| **المخرجات** | المساحة `S` |

### الخوارزمية

```
Algorithm Square_Area

Var
    a, S : Real;

Begin
    Read(a);
    S ← a * a;
    Write(S);
End
```

## 🧩 تمارين تدريجية

### 🟢 سهل — ضع خطًا تحت المعرّفات الصحيحة وعلّل رفض الباقي

| `age` | `var1` | `Moy_Bac` | `N°phone` |
|-------|--------|-----------|-----------|
| `3number` | `number-max` | `Price.TTC` | `False` |
| `Note info` | `String` | `^power` | `const` |

### 🟡 متوسط — صرّح بالتالي بالشكل الصحيح

| البيانة | التصريح الصحيح |
|--------|----------------|
| اسم شخص | `Var Nom : String;` |
| عدد الثواني في ساعة | `Const Sec_Per_Hour ← 3600;` |
| المسافة بين مدينتين | `Var Distance : Real;` |
| السنة الحالية 2026 | `Const Current_Year ← 2026;` |

### 🔴 تحدي — صحّح هذه التصريحات الخاطئة

```
Var
    age     : String;    ← الخطأ؟
    name    : Integer;   ← الخطأ؟
    moyenne : Boolean;   ← الخطأ؟
    success : Real;      ← هل هذا صحيح؟
```

---

## ⚠️ الأخطاء الشائعة

- ❌ **تسمية متغير باسم محجوز** — مثل `Read` أو `If` أو `True`
- ❌ **الخلط بين `Var` و `Const`** — المتغير يتغير، الثابت لا يتغير أبدًا
- ❌ **نسيان الفاصلة المنقوطة `;`** — كل تصريح ينتهي بـ `;`
- ❌ **اختيار نوع خاطئ** — لا تستخدم `Integer` للمعدل لأنه يحتوي فاصلة

---

## ⚡ مراجعة سريعة قبل الفرض

```
✔ الخوارزمية = رأس + تصريحات + تعليمات
✔ Var للمتغيرات — Const للثوابت
✔ 5 أنواع: Integer / Real / Character / String / Boolean
✔ المعرّف يبدأ بحرف — بدون فراغ — بدون كلمة محجوزة
✔ كل تصريح ينتهي بـ ;
✔ الخوارزمية تبدأ بـ Begin وتنتهي بـ End
```
