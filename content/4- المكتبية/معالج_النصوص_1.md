# 📝 معالج النصوص (Word) — الدرس الأول: الأنماط، القوالب، المقاطع
**المستوى:** السنة أولى أدبي + علمي | **المادة:** المكتبية

---

## 🎯 ماذا سنتعلم؟

نتعلم ثلاث أدوات قوية في Word تجعل مستنداتنا **منظمة، سريعة الإنجاز، واحترافية المظهر**.

---

## ⚡ ملخص سريع — البطاقات الثلاث

| الأداة | ما هي؟ | متى نستعملها؟ |
|---|---|---|
| **النمط (Style)** | مجموعة تنسيقات جاهزة تُطبَّق دفعة واحدة | لتوحيد مظهر النصوص والعناوين |
| **القالب (Template)** | نموذج مستند جاهز قابل للتعديل | لإنشاء شهادات، تقارير، سير ذاتية بسرعة |
| **المقطع (Section)** | جزء مستقل من المستند له تنسيقه الخاص | لتنويع التخطيط داخل نفس الملف |

---

## 📖 الشرح المبسط

---

### 🎨 1 — النمط (Style)

**ما هو؟** بدلًا من تغيير الخط والحجم واللون يدويًا في كل مرة، تحفظ كل هذه الإعدادات في **نمط واحد** وتطبقه بنقرة واحدة.

**فائدتان رئيسيتان:**
- ⏳ **توفير الوقت** — تنسيق دفعة واحدة
- 🎯 **توحيد المظهر** — الجميع بنفس الشكل

**أنواع الأنماط:**

| النوع | ما يشمل |
|---|---|
| نمط الحروف | الخط، الحجم، اللون فقط |
| نمط الفقرة | كل ما في الحروف + تباعد الأسطر + المحاذاة + الحدود |
| النمط المرتبط | يعمل كالنوعين معًا حسب التحديد |

---

### 📄 2 — القالب (Template)

**ما هو؟** مستند جاهز التصميم في Word — تفتحه وتملأ بياناتك فقط.

**أمثلة:** سيرة ذاتية، تقرير، شهادة مدرسية، رسالة رسمية.

**نوعان:**

#### أ) استخدام قالب جاهز
```
1. افتح Word
2. من الشاشة الرئيسية → More Templates
3. اختر القالب المناسب
4. انقر عليه → يفتح كمستند جاهز للتعديل ✅
```

#### ب) إنشاء قالب جديد من الصفر
```
1. افتح مستندًا جديدًا في Word
2. صمّمه كما تريد (تنسيق، عناوين، جداول...)
3. File → Save As
4. من نوع الملف اختر: Word Template (*.dotx)
5. احفظه في المكان المناسب ✅
```

---

### ✂️ 3 — المقطع (Section) والفواصل (Breaks)

**ما هو المقطع؟** جزء مستقل من المستند له تنسيقه الخاص — مثلًا صفحة أفقية وسط صفحات عمودية.

#### أنواع الفواصل:

**أ) فاصل الصفحة:**
- ينقل إلى صفحة جديدة فقط
- لا يغير تنسيق الصفحة

**ب) فاصل المقطع** — 3 أنواع:

| النوع | متى نستعمله |
|---|---|
| **Next Page** | بدء مقطع جديد في صفحة جديدة (انتقال بين فصول) |
| **Continuous** | مقطع جديد في نفس الصفحة (تغيير عدد الأعمدة) |
| **Even / Odd Page** | بدء مقطع في صفحة زوجية أو فردية |

**كيفية إدراج فاصل مقطع:**
```
1. ضع المؤشر في المكان المطلوب
2. تبويب Layout → Breaks
3. اختر نوع الفاصل المناسب ✅
```

---

## 🗺️ مخطط الفواصل

```
Breaks (الفواصل)
        │
   ┌────┴────────────────────┐
   │                          │
فاصل صفحة               فاصل مقطع
(Page Break)           (Section Break)
ينتقل فقط                    │
                    ┌─────────┼──────────┐
                    │         │          │
                Next Page  Continuous  Even/Odd
                صفحة جديدة  نفس الصفحة  زوجية/فردية
```

---

## ✅ مثال محلول — حل التقويم

| الوضعية | الحل | السبب |
|---|---|---|
| صفحة أولى بها صورة، والثانية بأعمدة لمقال | **فاصل مقطع Continuous** | لتغيير تنسيق الصفحة (عدد الأعمدة) |
| آيات قرآنية بنفس الخط في كل صفحة | **نمط (Style)** | تطبيق تنسيق موحد دفعة واحدة |
| شهادة مدرسية لـ 70 تلميذًا بسرعة | **قالب (Template)** | نموذج جاهز يُعبأ بالأسماء بسرعة |

---

## ⚠️ الأخطاء الشائعة

- **الضغط على Enter مرات كثيرة للانتقال إلى صفحة جديدة** → استعمل فاصل الصفحة بدلًا من ذلك.
- **تنسيق كل عنوان يدويًا** → استعمل الأنماط لتوحيد المظهر وتوفير الوقت.
- **حفظ القالب بامتداد `.docx` عوض `.dotx`** → سيصبح مستندًا عاديًا لا قالبًا.

---

## 📝 تمارين للتطبيق

### 🟢 سهل
1. أنشئ نمطًا للعناوين: خط **Bold**، حجم **16**، لون **أزرق**.
2. طبّق النمط على 3 عناوين في مستند.

### 🟡 متوسط
1. افتح Word وابحث عن قالب "سيرة ذاتية".
2. عدّله بمعلوماتك واحفظه.

### 🔴 تحدّي
أنشئ مستندًا فيه:
- صفحة أولى بعمود واحد (مقدمة)
- صفحة ثانية بعمودين (مقال)
- صفحة ثالثة أفقية (جدول)
*(تلميح: استعمل فواصل المقاطع)*

---

## 🔁 مراجعة سريعة قبل الفرض

```
✔ النمط (Style) = تنسيق جاهز يُطبَّق بنقرة واحدة
✔ 3 أنواع: نمط الحروف | نمط الفقرة | النمط المرتبط
✔ القالب (Template) = مستند جاهز (*.dotx)
✔ حفظ قالب: Save As → Word Template (*.dotx)
✔ المقطع = جزء مستقل بتنسيقه الخاص
✔ فاصل المقطع: Layout → Breaks
✔ Next Page / Continuous / Even-Odd
```
