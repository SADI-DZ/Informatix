# 🎨 العروض التقديمية (PowerPoint) — الدرس الأول
**المستوى:** السنة أولى أدبي + علمي | **المادة:** المكتبية

---

## 🎯 ماذا سنتعلم؟

نتعرف على برنامج **PowerPoint**، مكوناته، وكيفية إنشاء عرض تقديمي احترافي من الصفر — من إضافة الشرائح إلى حفظ الملف.

---

## ⚡ ملخص سريع

> **PowerPoint** = برنامج من حزمة Microsoft Office لإنشاء عروض تقديمية مكوّنة من **شرائح (Slides)** تحتوي على نصوص وصور وأشكال.
>
> يُستعمل في: التعليم — العروض التجارية — المؤتمرات — التقارير.

---

## 🗂️ مكونات واجهة PowerPoint — دليل سريع

```
┌──────────────────────────────────────┐
│         شريط العنوان (اسم الملف)    │
├──────────────────────────────────────┤
│         شريط الأدوات (تنسيق سريع)  │
├───────────┬──────────────────────────┤
│           │                          │

├──────────────────────────────────────┤

└──────────────────────────────────────┘
```

## 📖 الشرح المبسط

### 1️⃣ إنشاء عرض تقديمي جديد

```
1. افتح برنامج PowerPoint
2. اختر "عرض تقديمي فارغ"
3. ستظهر الشريحة الأولى (شريحة العنوان)
4. اكتب العنوان والنص
```

---

### 2️⃣ إضافة شرائح جديدة

```
الصفحة الرئيسية ← شريحة جديدة ← اختر النوع المناسب
```

**أنواع الشرائح الشائعة:**
- شريحة عنوان فقط
- شريحة عنوان + نص
- شريحة فارغة
- شريحة بصورة

---

### 3️⃣ إدراج العناصر في الشريحة

| العنصر | الطريقة |
|---|---|
| 📝 نص | Insert → Text → **Text Box** |
| 🖼️ صورة | Insert → **Image** → اختر الصورة من مجلدك |
| 🎬 فيديو | Insert → **Video** → اختر الفيديو من مجلدك |
| 🔊 صوت | Insert → **Audio** → اختر الصوت من مجلدك |

---

### 4️⃣ حفظ العرض التقديمي

```
1. انقر على ملف → حفظ باسم
2. اختر مكان الحفظ
3. اكتب اسم الملف
4. تأكد من الامتداد: *.pptx
5. انقر حفظ ✅
```

---

## ✅ مثال محلول — إنشاء عرض عن "البيئة"

**المطلوب:** إنشاء عرض تقديمي من 3 شرائح عن موضوع "حماية البيئة".

| الشريحة | المحتوى | الخطوات |
|---|---|---|
| 1 | العنوان: "حماية البيئة" | شريحة عنوان — اكتب العنوان |
| 2 | أسباب التلوث (نقاط) | أضف شريحة جديدة → نص — أضف النقاط |
| 3 | صور للطبيعة | أضف شريحة جديدة → Insert → Image |

**الحفظ:** File → Save As → اسم "حماية_البيئة" → حفظ بـ `*.pptx`

---

## ⚠️ الأخطاء الشائعة

- **نسيان حفظ الملف بامتداد `.pptx`** → قد لا يفتح على أجهزة أخرى.
- **وضع نص كثير في شريحة واحدة** → الشريحة تصبح ثقيلة وغير جذابة.
  - ✅ القاعدة: **6 كلمات في السطر، 6 أسطر في الشريحة** (قاعدة 6×6).
- **عدم اختيار نوع الشريحة المناسب** → التنسيق يصبح فوضويًا.

---

## 📝 تمارين للتطبيق

### 🟢 سهل
أنشئ عرضًا من شريحتين:
- الأولى: عنوان "درسي اليوم"
- الثانية: 3 نقاط عن مادتك المفضلة

### 🟡 متوسط
أنشئ عرضًا عن مدينتك من 4 شرائح (عنوان، تاريخ، معالم، صورة)، ثم احفظه بـ `*.pptx`.

### 🔴 تحدّي
أنشئ عرضًا من 5 شرائح يشمل: نصوص، صورة، وصوت. ثم احفظه وشاركه مع زميلك.

---

## 🔁 مراجعة سريعة قبل الفرض

```
✔ PowerPoint = برنامج عروض تقديمية (Slides)
✔ الشريحة = صفحة واحدة داخل العرض
✔ الشريحة الجديدة: الصفحة الرئيسية → شريحة جديدة
✔ إدراج نص: Insert → Text Box
✔ إدراج صورة/فيديو/صوت: Insert → Image/Video/Audio
✔ الحفظ: File → Save As → *.pptx
```
