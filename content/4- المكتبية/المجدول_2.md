# 📊 المجدول (Excel) — الدرس الثاني: فرز البيانات
**المستوى:** السنة أولى أدبي + علمي | **المادة:** المكتبية

---

## 🎯 ماذا سنتعلم؟

نتعلم كيف **نرتّب البيانات** داخل جدول Excel بطريقة سريعة أو مخصصة، لتسهيل القراءة وتحليل المعلومات.

---

## ⚡ ملخص سريع

> **فرز البيانات** = ترتيب محتوى الجدول وفق معيار معين (أبجدي، عددي، أو تاريخي).

**اتجاهان:**

| الاتجاه | المعنى | مثال |
|---|---|---|
| ⬆️ تصاعدي | من الأصغر إلى الأكبر | A → Z أو 1 → 100 |
| ⬇️ تنازلي | من الأكبر إلى الأصغر | Z → A أو 100 → 1 |

---

## 🗂️ خريطة الفرز

```
فرز البيانات في Excel
        │
   ┌────┴────┐
   │         │
سريع      مخصص
(عمود    (عدة
واحد)    أعمدة)
```

---

## 📖 الشرح المبسط

### 1️⃣ الفرز السريع — عمود واحد

**متى نستعمله؟** عندما نريد ترتيب الجدول حسب عمود واحد فقط (مثلًا: ترتيب الأسماء أبجديًا).

**الخطوات:**

```
1. انقر على أي خلية داخل العمود المراد فرزه
2. اذهب إلى تبويب  Data
3. اختر:
   - Sort A to Z  ← للفرز التصاعدي ⬆️
   - Sort Z to A  ← للفرز التنازلي ⬇️
4. يرتّب الجدول تلقائيًا ✅
```

---

### 2️⃣ الفرز المخصص — عدة أعمدة

**متى نستعمله؟** عندما نريد ترتيبًا أكثر دقة (مثلًا: ترتيب حسب الاسم أولًا، ثم حسب العلامة).

**الخطوات:**

```
1. حدّد الجدول كاملًا
2. اذهب إلى  Data → Sort
3. ستظهر نافذة Sort
4. اختر في كل حقل:
   ┌──────────────────────────────────┐
   │  Column  →  اسم العمود          │
   │  Sort On →  Values              │
   │  Order   →  A to Z / Z to A ... │
   └──────────────────────────────────┘
5. اضغط OK ✅
```

---

## ✅ مثال محلول خطوة بخطوة

**المعطيات:** جدول فيه أسماء تلاميذ وعلاماتهم، نريد ترتيبهم من الأعلى علامة إلى الأدنى.

| الاسم | العلامة |
|---|---|
| أمين | 12 |
| سارة | 18 |
| كريم | 15 |

**الخطوات:**
1. حدّد الجدول كاملًا (مع العنوان)
2. اذهب إلى **Data → Sort**
3. في نافذة Sort:
   - **Column:** العلامة
   - **Sort On:** Values
   - **Order:** Largest to Smallest
4. اضغط **OK**

**النتيجة:**

| الاسم | العلامة |
|---|---|
| سارة | 18 |
| كريم | 15 |
| أمين | 12 |

---

## 🆚 مقارنة بين نوعي الفرز

| | الفرز السريع | الفرز المخصص |
|---|---|---|
| **عدد الأعمدة** | عمود واحد | عدة أعمدة |
| **الوصول إليه** | Data → Sort A-Z/Z-A | Data → Sort |
| **التعقيد** | بسيط جدًا | أكثر خيارات |
| **الاستعمال** | فرز سريع | تحليل دقيق |

---

## ⚠️ الأخطاء الشائعة

- **عدم تحديد الجدول كاملًا** قبل الفرز المخصص → ستُفرز بيانات ناقصة.
- **نسيان صف العنوان** → قد يُدرج العنوان ضمن البيانات المفرزة.
  - ✅ الحل: تأكد من تفعيل خيار **"My data has headers"** في نافذة Sort.
- **الفرز على خلية فارغة** → لن تحصل على نتيجة صحيحة.

---

## 📝 تمارين للتطبيق

### 🟢 سهل
لديك قائمة أسماء: زينب، أحمد، مريم، خالد، نور.
- رتّبها أبجديًا تصاعديًا باستعمال الفرز السريع.

### 🟡 متوسط
لديك جدول فيه أسماء تلاميذ وعلاماتهم ومعدلاتهم.
- رتّبهم من أعلى معدل إلى أدنى معدل باستعمال الفرز المخصص.

### 🔴 تحدّي
لديك جدول فيه: الاسم، القسم، والعلامة.
- رتّب الجدول أولًا حسب **القسم** أبجديًا، ثم داخل كل قسم حسب **العلامة** تنازليًا.

---

## 🔁 مراجعة سريعة قبل الفرض

```
✔ الفرز = ترتيب البيانات (تصاعدي أو تنازلي)
✔ الفرز السريع  → عمود واحد → Data → Sort A to Z / Z to A
✔ الفرز المخصص → عدة أعمدة → Data → Sort → نافذة الإعداد
✔ في نافذة Sort: Column + Sort On (Values) + Order
✔ تأكد دائمًا من تحديد الجدول كاملًا قبل الفرز المخصص
```

---

> 🖼️ **مقترح للموقع:** أضف صورة لنافذة Sort مع تسمية الحقول الثلاثة (Column / Sort On / Order).
> 🎮 **مقترح:** تمرين تفاعلي — جدول يطلب من التلميذ ترتيبه بالنقر على الأزرار.
