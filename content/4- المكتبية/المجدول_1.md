# 📊 المجدول (Excel) — الدرس الأول
**المستوى:** السنة أولى أدبي + علمي | **المادة:** المكتبية

---

## 🎯 ماذا سنتعلم في هذا الدرس؟

نتعرّف على برنامج **Excel** وأهم مكوناته، ونتعلم كيف نكتب **صيغًا** و**دوالًا** لإجراء الحسابات بشكل آلي وسريع.
هذا الدرس هو أساس كل عمل على الجداول الحسابية!

---

## ⚡ ملخص سريع — البطاقات الأساسية

| المصطلح | التعريف المختصر |
|---|---|
| **Excel** | برنامج لإنشاء جداول وإجراء حسابات ورسم مخططات (امتداده: `*.xlsx`) |
| **المصنف** | ملف العمل — يحتوي على ورقة عمل أو أكثر |
| **ورقة العمل** | صفحة داخل المصنف تتكون من صفوف وأعمدة |
| **الخلية** | تقاطع صف مع عمود — أصغر وحدة في الجدول (مثال: `A1`) |
| **الصيغة** | عملية حسابية تبدأ بـ `=` |
| **الدالة** | صيغة جاهزة لتسهيل الحسابات |

---

## 🗂️ مخطط هيكل Excel

```
المصنف (Workbook)
├── ورقة العمل 1 (Sheet1)
│   ├── صفوف  (1 → 1,048,576)
│   ├── أعمدة (A → XFD)
│   └── خلايا  (A1, B2, C3...)
├── ورقة العمل 2
└── ورقة العمل 3
```

---

## 📖 الشرح المبسط

### 1️⃣ الصيغ (Formules)
كل عملية حسابية في Excel تبدأ بـ **=**

**نوعان:**
- **مباشرة** → تكتب الأرقام مباشرة: `= 35 * 5`
- **بمراجع الخلايا** → تستعمل أسماء الخلايا: `= A5 + B5`

> 💡 **النصيحة:** دائمًا استعمل مراجع الخلايا — إذا تغيّرت القيمة، تتغير النتيجة تلقائيًا!

### 2️⃣ الدوالّ (Functions)
صيغة جاهزة يكتبها Excel لك — فقط تعطيها الخلايا!

**الشكل العام:**
```
= اسم_الدالة(وسائط)
```

---

## 🔢 أهم الدوالّ — جدول مرجعي

| الدالة | الوظيفة | مثال |
|---|---|---|
| `SUM()` | حساب المجموع | `=SUM(A1:A10)` |
| `AVERAGE()` | حساب الوسط الحسابي | `=AVERAGE(B1:B5)` |
| `MAX()` | أكبر قيمة | `=MAX(C1:C20)` |
| `MIN()` | أصغر قيمة | `=MIN(C1:C20)` |
| `IF()` | شرط (إذا/إلا) | `=IF(A1>=10;"ناجح";"راسب")` |

---

## ✅ أمثلة محلولة

### مثال 1 — حساب مجموع درجات تلميذ

**المعطيات:**
- خلية `B2` = 14 (رياضيات)
- خلية `C2` = 16 (علوم)
- خلية `D2` = 12 (عربية)

**خطوات الحل:**
1. اضغط على الخلية التي تريد فيها النتيجة (مثلًا `E2`)
2. اكتب: `=SUM(B2:D2)`
3. اضغط **Enter**

**النتيجة:** `42`

---

### مثال 2 — دالة IF (الشرطية)

**المطلوب:** كتابة "ناجح" إذا كانت العلامة ≥ 10، و"راسب" إذا كانت أقل.

**المعطيات:** العلامة في الخلية `A2`

**الصيغة:**
```
=IF(A2>=10;"ناجح";"راسب")
```

**شرح الصيغة:**
```
IF(  الشرط  ;  إذا تحقق  ;  إذا لم يتحقق  )
```

---

## ⚠️ الأخطاء الشائعة

| الخطأ | الصحيح |
|---|---|
| نسيان علامة `=` في بداية الصيغة | دائمًا ابدأ بـ `=` |
| استعمال `,` بدل `;` للفصل بين الوسائط | استعمل `;` في النسخة العربية |
| الخلط بين `:` و `;` | `:` للنطاق (A1:A10) — `;` للفصل بين خليتين مختلفتين |
| نسيان إغلاق القوس `)` | Excel سيُنبّهك بخطأ |

## 📝 تمارين للتطبيق

### 🟢 سهل
لديك هذه الجدول: الخلية `A1=8` و `A2=12` و `A3=15`
1. أوجد المجموع باستعمال `SUM`
2. أوجد الوسط الحسابي باستعمال `AVERAGE`

### 🟡 متوسط
لديك قائمة علامات 5 تلاميذ في الخلايا `B1` إلى `B5`.
1. أوجد أعلى علامة.
2. أوجد أدنى علامة.
3. استعمل `IF` لكتابة "ممتاز" إذا كانت العلامة ≥ 16.

### 🔴 تحدّي
لديك جدول فيه أسماء 10 تلاميذ وعلاماتهم في 3 مواد.
- احسب معدل كل تلميذ.
- استعمل `IF` لتحديد من هو "ناجح" أو "راسب".
- استخرج أعلى معدل في الفصل.

## 🔁 مراجعة سريعة قبل الفرض

```
✔ Excel = جداول + حسابات + مخططات (*.xlsx)
✔ الخلية = تقاطع صف + عمود (مثال: A1)
✔ كل صيغة تبدأ بـ =
✔ الفاصلة المنقوطة ; تفصل بين الوسائط
✔ النقطتان : تحددان نطاق خلايا متجاورة
✔ SUM / AVERAGE / MAX / MIN / IF = أهم 5 دوالّ
✔ IF(شرط ; إذا تحقق ; إذا لم يتحقق)
```
