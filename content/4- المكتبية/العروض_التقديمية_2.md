# 🎨 العروض التقديمية (PowerPoint) — الدرس الثاني: الحركات والارتباطات
**المستوى:** السنة أولى أدبي + علمي | **المادة:** المكتبية

---

## 🎯 ماذا سنتعلم؟

نتعلم كيف نجعل عرضنا التقديمي **حيًا وتفاعليًا** بإضافة حركات للشرائح والعناصر، وإنشاء روابط تشعبية تنقل المشاهد بين الشرائح.

---

## ⚡ ملخص سريع

```
الحركات في PowerPoint
         │
   ┌─────┴──────┐
   │             │
انتقالية      مخصصة
(Transition)  (Animation)
بين الشرائح  على العناصر
             (نص، صورة...)
```

---

## 📖 الشرح المبسط

### 1️⃣ الحركة الانتقالية (Transition)

**ما هي؟** التأثير الذي يظهر عند الانتقال **من شريحة إلى أخرى**.

**خطوات الإضافة:**
```
1. حدّد الشريحة
2. اذهب إلى تبويب Transition
3. اختر نوع الحركة
```

**خيارات إضافية:**
- 🔊 إضافة **صوت** مع الحركة
- ⏱️ ضبط **سرعة** الحركة
- 🖱️ اختيار **الانطلاق**: بالنقر أو تلقائيًا
- 📋 تطبيق على **جميع الشرائح** دفعة واحدة

---

### 2️⃣ الحركة المخصصة (Animation)

**ما هي؟** مؤثرات بصرية تُضاف على **العناصر داخل الشريحة** (نص، صورة، شكل...).

**خطوات الإضافة:**
```
1. حدّد العنصر (نص أو صورة)
2. اذهب إلى تبويب Animation
3. اختر: "إضافة حركة" → نوع الحركة
```

> 💡 يمكنك إضافة صوت مع الحركة المخصصة أيضًا!

---

### 3️⃣ مقارنة بين النوعين

| | Transition | Animation |
|---|---|---|
| **تُطبَّق على** | الشريحة كاملة | عنصر داخل الشريحة |
| **متى تظهر** | عند الانتقال بين الشرائح | عند ظهور العنصر على الشاشة |
| **تبويبها** | Transition | Animation |
| **مثال** | تأثير "التلاشي" بين الشرائح | نص يطير من اليسار |

---

### 4️⃣ عرض النتيجة وإنهاؤها

| الإجراء | الطريقة |
|---|---|
| ▶️ بدء العرض | زر **Diaporama** أو مفتاح **F5** |
| ⏹️ إنهاء العرض | مفتاح **Echap** |

---

### 5️⃣ الارتباطات التشعبية (Hyperlinks)

**ما هي؟** رابط يربط شريحة بـ: شريحة أخرى، ملف آخر، أو صفحة ويب.

**خطوات الإنشاء:**
```
1. اكتب نصًا أو أدرج كائنًا (صورة / شكل)
2. حدّد العنصر
3. اذهب إلى Insert → رابط تشعبي
4. حدّد الهدف:
   - شريحة أخرى في نفس العرض
   - ملف خارجي
   - صفحة ويب
```

---

### 6️⃣ أزرار الإجراء (Action Buttons)

**ما هي؟** أزرار جاهزة تُضاف للشريحة للانتقال بين الشرائح بسهولة.

**خطوات الإضافة:**
```
1. تبويب Home → مجموعة Drawing
2. اختر زر إجراء
3. ارسم الزر على الشريحة
4. حدّد وظيفته:
   ← الموالية | السابقة | الأولى | الأخيرة | الرئيسية
```

---

## ✅ مثال محلول

**المطلوب:** إنشاء عرض عن "الماء" مع حركة انتقالية وارتباط تشعبي.

**الخطوات:**
1. أنشئ 3 شرائح (عنوان، أهمية الماء، صورة)
2. طبّق **Transition → Fade** على جميع الشرائح
3. في الشريحة الأولى، اكتب "▶ اضغط هنا للمزيد"
4. حدّد النص → Insert → Hyperlink → الشريحة 2
5. اضغط **F5** لتجربة العرض

---

## ⚠️ الأخطاء الشائعة

- **كثرة الحركات في شريحة واحدة** → تشتيت المشاهد.
  - ✅ القاعدة: حركة أو اثنتان بحد أقصى لكل شريحة.
- **استعمال Transition مختلف لكل شريحة** → العرض يبدو فوضويًا.
  - ✅ اختر نمطًا واحدًا وطبّقه على الكل.
- **نسيان تحديد العنصر** قبل إضافة Animation.
- **الارتباط التشعبي لا يعمل** → تأكد أنك في وضع العرض (F5)، لا في وضع التحرير.

---

## 📝 تمارين للتطبيق

### 🟢 سهل
أضف حركة انتقالية **Fade** لجميع شرائح عرضك السابق.

### 🟡 متوسط
أضف Animation على عنوان الشريحة الأولى بحيث يظهر من اليسار، وأضف صوتًا معه.

### 🔴 تحدّي
أنشئ عرضًا تفاعليًا: في الشريحة الأولى، أزرار إجراء تنقل إلى 3 شرائح مختلفة (مواضيع مختلفة)، مع رابط "العودة للرئيسية" في كل شريحة.

---

## 🔁 مراجعة سريعة قبل الفرض

```
✔ Transition = حركة بين الشرائح ← تبويب Transition
✔ Animation = حركة على عنصر ← تبويب Animation
✔ بدء العرض: F5 | إنهاؤه: Echap
✔ Hyperlink = رابط من عنصر إلى شريحة / ملف / ويب
✔ أزرار الإجراء: Home → Drawing → زر إجراء
✔ لا تكثر من الحركات — البساطة أجمل!
```
