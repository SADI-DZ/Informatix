# 🖥️ تجميع الحاسوب

**المستوى:** سنة أولى ثانوي — علمي وآداب
**الوحدة:** الثانية | المجال: بيئة التعامل مع الحاسوب

---

## 🎯 مقدمة سريعة

الحاسوب ليس سحرًا — إنه قطع متصلة ببعضها بطريقة ذكية.  
في هذا الدرس ستتعرف على جميع مكونات الحاسوب، وكيف يُمثّل البيانات داخليًا، وستتعلم حساب أحجام الملفات بسهولة.

---

## 📋 ملخص سريع

| المفهوم | المعنى المختصر |
|--------|--------------|
| **البت (Bit)** | أصغر وحدة معلومات = 0 أو 1 |
| **البايت (Byte)** | 8 بتات = يُمثّل حرفًا واحدًا |
| **RAM** | ذاكرة سريعة مؤقتة (تُفقد عند الإطفاء) |
| **ROM** | ذاكرة ثابتة للتعليمات الأساسية |
| **SSD** | قرص تخزين سريع وصلب بدون أجزاء متحركة |
| **HDD** | قرص تخزين ميكانيكي رخيص لكن أبطأ |

## 🗺️ مخطط مكونات الحاسوب

```
┌─────────────────────────────────────────┐
│             الحـاسـوب                   │
├──────────────┬──────────────────────────┤
│ مكونات مادية │  مكونات غير مادية         │
│  (Hardware)  │  أنظمة تشغيل + برامج     │
└──────┬───────┘                          │
       │                                  │
  ┌────┴──────────────────────────────┐   │
  │         الوحدة المركزية           │   │
  │  علبة التغذية • اللوحة الأم       │   │
  │  المعالج • RAM • ROM              │   │
  │  بطاقات: صوت / شبكة / رسوميات    │   │
  │  وحدات التخزين: SSD أو HDD        │   │
  └────────────────────────────────── ┘
       ↑ إدخال              ↓ إخراج
  لوحة مفاتيح            شاشة
  فأرة                   طابعة
  ميكروفون               سماعات
```

> 📸 **مقترح:** أضف صورة حقيقية للوحة أم مع تسمية كل مكوّن

## 📖 الشرح المبسط

### 🔹 كيف يفهم الحاسوب البيانات؟
الحاسوب يفهم فقط **كهرباء موجودة (1) أو غائبة (0)**.  
هذا ما نسميه **النظام الثنائي**.

- الحرف `A` مثلًا = `01000001` في الذاكرة
- الرقم `5` مثلًا = `00000101`

### 🔹 جدول وحدات التخزين

| الوحدة | تساوي |
|--------|------|
| 1 Byte (B) | 8 Bits |
| 1 KiloByte (KB) | 1024 B |
| 1 MegaByte (MB) | 1024 KB |
| 1 GigaByte (GB) | 1024 MB |
| 1 TeraByte (TB) | 1024 GB |

> 💡 **حيلة الحفظ:** كل مرة نضرب أو نقسم في **1024** للانتقال بين الوحدات.

### 🔹 SSD مقابل HDD

| | SSD | HDD |
|-|-----|-----|
| **السرعة** | ⚡ سريع جدًا | 🐢 أبطأ نسبيًا |
| **الصدمات** | ✅ مقاوم | ❌ حساس |
| **السعر** | 💰 أغلى | 💵 أرخص |
| **السعة** | محدودة أحيانًا | كبيرة جدًا |

## 🧮 أمثلة محلولة

### مثال 1 — تخزين كلمة

**السؤال:** كم بتًا تحتاج كلمة "computer" لتخزينها؟

| الخطوة | الحساب |
|--------|--------|
| عدد الحروف | 8 حروف |
| كل حرف = 8 بت | 8 × 8 |
| **النتيجة** | **64 بت** |

---

### مثال 2 — تحويل الوحدات

**السؤال:** كم تساوي 3 MB بالبايت؟

```
3 MB × 1024 = 3072 KB
3072 KB × 1024 = 3,145,728 B
```
✅ **الجواب: 3,145,728 بايت**

---

### مثال 3 (مسألة كاملة) — حساب مساحة قرص صلب

**المعطيات:**
- قرص صلب: **2 TB** = 2 × 1024 = **2048 GB**
- ملفات فيديو: 512 GB
- ملفات صوتية: 204,800 MB
- ملفات صور: 1,048,576 KB
- برامج: 819,200 KB

**الخطوة 1 — التحويل إلى GB:**

| الملف | الحجم الأصلي | ÷ التحويل | = بـ GB |
|------|-------------|----------|--------|
| الفيديو | 512 GB | — | **512 GB** |
| الصوت | 204,800 MB | ÷ 1024 | **200 GB** |
| الصور | 1,048,576 KB | ÷ 1024 ÷ 1024 | **1 GB** |
| البرامج | 819,200 KB | ÷ 1024 ÷ 1024 | **0.78 GB** |

**الخطوة 2 — المجموع:**
```
512 + 200 + 1 + 0.78 = 713.78 GB
```

**الخطوة 3 — المساحة المتبقية:**
```
2048 - 713.78 = 1334.22 GB
```

**الخطوة 4 — بالميغابايت:**
```
1334.22 × 1024 = 1,365,217.28 MB
```

✅ **المساحة المتبقية = 1334.22 GB ≈ 1,365,217 MB**

## ❌ الأخطاء الشائعة

> ⚠️ **خطأ 1:** الضرب بـ 1000 بدل 1024 — الصحيح دائمًا 1024 في علم الحاسوب.

> ⚠️ **خطأ 2:** الخلط بين RAM (مؤقتة) و ROM (دائمة).

> ⚠️ **خطأ 3:** نسيان تحويل جميع الوحدات إلى نفس الوحدة قبل الجمع.

> ⚠️ **خطأ 4:** الاعتقاد بأن TB = 1000 GB — الصحيح هو 1024 GB.

## ✏️ تمارين التطبيق

### 🟢 سهل
1. حوّل: `4096 MB = ? GB`
2. حوّل: `0.5 TB = ? GB`
3. كلمة "ecole" — كم بتًا تحتاج؟

### 🟡 متوسط
4. حوّل: `1.5 GB = ? Bits`
5. حوّل: `512 KB = ? Bytes`
6. قرص صلب سعته 500 GB، مُستخدم منه 358,400 MB. ما المساحة المتبقية بالـ GB؟

### 🔴 تحدي
7. عندك قرص صلب 1 TB. تريد تخزين:
   - 200 ملف فيديو، كل واحد 2 GB
   - 5000 صورة، كل صورة 4 MB
   - 300 أغنية، كل واحدة 5 MB
   هل يكفي القرص؟ وما المساحة المتبقية بالـ MB؟

## 🔁 مراجعة سريعة قبل الفرض

```
✔ الحاسوب = يستقبل → يعالج → يُظهر النتائج
✔ المكونات: مادية (Hardware) وغير مادية (Software)
✔ البت = 0 أو 1 | البايت = 8 بتات
✔ الترتيب: Bit → Byte → KB → MB → GB → TB (×1024)
✔ RAM = مؤقتة وسريعة | ROM = ثابتة
✔ SSD = سريع وغالي | HDD = بطيء ورخيص
✔ للتحويل للأعلى: ÷ 1024 | للأسفل: × 1024
✔ للتحويل من Byte إلى Bit: × 8 | العكس: ÷ 8
```
